## Aggregate integration

This pull request is maintained as one review surface. Automation updates the integration branch only after validation and never creates, edits, or closes pull requests.

The current exact-SHA results, aggregate benchmark deltas, and commits since the prior nightly are in the [single updating nightly report](https://github.com/usr-bin-roygbiv/rmux/blob/nightly-integration/integration/nightly/report.md).

The fork commit status and aggregate pull request Checks pages are public. Woodpecker UI and logs remain private and are not required to review the public result.

Correspondence and approval remain manual.
